# Sunfort Solar

A single-page marketing site for a solar &amp; battery installation company for the Nigerian market, with a live system-sizing cost calculator.

**Demo site** — "Sunfort" is a placeholder brand and pricing is indicative.

## Hosting
This is a single, self-contained static file (`index.html`) — fonts and images are embedded, no build step. Deploy on any static host:

- **Vercel:** Import this repo (no framework, no build command) or drag the folder onto the dashboard.
- Loads at the root URL automatically because the page is named `index.html`.
